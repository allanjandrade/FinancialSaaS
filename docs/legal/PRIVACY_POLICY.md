# Politica de privacidade

O aplicativo coleta dados de conta, dados financeiros informados pelo usuario, configuracoes, logs operacionais sanitizados, eventos de billing, uso de IA e dados minimos de busca de precos.

Dados financeiros nao sao enviados ao gateway de pagamento. ValueSERP recebe apenas query tecnica de produto. IA e logs devem usar dados minimizados.

O usuario pode solicitar exportacao, correcao e exclusao de dados. Logs nao devem conter tokens, secrets, `finance_states`, payload bruto de IA ou payload bruto de gateway.
