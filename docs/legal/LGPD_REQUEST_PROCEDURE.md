# Procedimento de Solicitação de Direitos LGPD

Versão: 2026-06-20-r11.2

Para exercer direitos previstos na LGPD, envie mensagem para allanjonasandrade@gmail.com com o assunto "Direitos LGPD - Controle Financeiro".

Informe:

- nome e e-mail da conta;
- direito que deseja exercer;
- informações suficientes para confirmar sua identidade com segurança.

Responderemos conforme os prazos previstos na legislação aplicável.
