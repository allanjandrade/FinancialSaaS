# Aviso de Tratamento de Dados

Versão: 2026-06-20-r11.2

Aplicação: Controle Financeiro

Responsável: Allan Jonas Andrade

Canal de contato e LGPD: allanjonasandrade@gmail.com

O Controle Financeiro trata dados pessoais e financeiros para manter a conta, organizar informações cadastradas pelo usuário, gerar saldos, relatórios, previsões, alertas, compras planejadas e recursos inteligentes.

Não vendemos seus dados financeiros. Não enviamos seu histórico financeiro completo para provedores de preço. Não usamos seus dados para prometer rendimento financeiro.

Dados de pagamento podem ser tratados por provedor especializado quando houver assinatura ativa. O aplicativo não armazena número completo de cartão.
